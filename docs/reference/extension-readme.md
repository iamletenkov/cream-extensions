# Шаблон README расширения

У каждого расширения каталога README одного вида: читатель находит ответ на
один и тот же вопрос в одном и том же месте. Каркас `tools/new-extension.sh`
кладёт этот шаблон сам; `tools/catalog-docs.sh --check` (часть `make test`)
требует в каждом README оба сгенерированных блока.

## Разделы по порядку

| Раздел | Что в нём | Обязателен |
|---|---|---|
| `# <имя>` и абзац под ним | что делает расширение — одна-три фразы, без истории версий | да |
| блок `catalog:facts` | ОС, архитектура, `cream`, способности, зависимости, хуки, стадия configure, действия, живая машина — генерируется из манифеста | да |
| `## Что делает` | что ставит и меняет каждый хук; что снимает `remove` | да |
| `## Параметры` | блок `catalog:params` (таблица `config.keys`) и под ним — что важно знать о ключах сверх таблицы | да |
| `## Установка` | пример на живой машине и строка VMFILE bisquite | да |
| `## Этапы` | что происходит при сборке образа, на загрузке, при `cream set`, при `remove`; действия | да, кроме библиотек |
| `## Известные ограничения` | чего расширение не делает, где не проверено, известные ловушки; «нет» — тоже ответ | да |
| `## Подробности` | обоснования, замеры, «Проверено на», диагностика — подразделами `###` | по нужде |
| `## Проверки` | V, H, L: чем расширение проверено в CI и локально | да |

Блоки между маркерами `<!-- catalog:facts -->` … `<!-- /catalog:facts -->` и
`<!-- catalog:params -->` … `<!-- /catalog:params -->` руками не правят: их
переписывает `tools/catalog-docs.sh` из `extension.yaml`. Изменился манифест —
запусти скрипт и закоммить README вместе с манифестом.

## Правила текста

- **Версий в тексте нет.** Версию расширения знает манифест, версию каталога —
  тег выпуска; «с 2.1.0» и таблицы переименований устаревают. История — в
  [`CHANGELOG.md`](../../CHANGELOG.md) и [docs/history/](../history/README.md).
- **Команды — как в cream 1.2.0.** Живая машина: `sudo cream install --with-deps
  <имя> KEY=VALUE`; образ: `RUN_COMMAND cream install --with-deps <имя>
  KEY=VALUE`. Секрет — `KEY=-` со stdin или `--params-file`, не в argv; в VMFILE — через
  `--mount=type=secret` и `--params-file`, никогда литералом.
- **Ссылки относительные**, на соседние расширения — `../<имя>/README.md`.
- Разделы, на которые ссылаются хуки (`README, «Как снять»`), сохраняют
  заголовок дословно.

## Установка

На машине с подключённым каталогом ([как подключить](../../../docs/getting-started.md)):

```bash
sudo cream install --with-deps <имя> KEY=VALUE
cream show <имя>
```

В образе bisquite (VMFILE):

```dockerfile
RUN_COMMAND cream install --with-deps <имя> KEY=VALUE
```
