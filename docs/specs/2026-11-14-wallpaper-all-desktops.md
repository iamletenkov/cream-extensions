# Обои существующих рабочих столов (#156)

## Цель и контракт

Картинка видна после следующего входа в GNOME, Xfce, Xubuntu, LXDE и LXQt,
включая уже входивших пользователей. Remove возвращает исходные wallpaper-свойства;
остальные личные настройки сохраняются. Работающий сеанс принудительно не завершаем.

## Дизайн

1. GNOME сохраняет системные dconf-значения с блокировками; личная база не меняется.
2. Xfce получает отдельный XDG-слой; Xsession добавляет его перед слоем Xubuntu.
3. Личные настройки Xfce/pcmanfm меняются только при `WALLPAPER_OVERRIDE_USER=1`.
4. Правятся только wallpaper-свойства; прочие настройки остаются пользовательскими.
5. Пользовательский помощник работает от имени пользователя, сохраняет исходные
   свойства и метку в его конфигурации; root не пишет в домашние каталоги.
6. Для исключения перезаписи кешем DE configure/remove с этим флагом требуют выхода
   из графических сеансов затронутых пользователей; эффект — при следующем входе.
7. Первый вход также проходит помощник Xsession, поэтому remove убирает и значения,
   автоматически созданные xfdesktop из нашего умолчания.
8. Remove восстанавливает только управляемые свойства; повтор не заменяет снимок.
9. LXQt использует pcmanfm-qt `[Desktop]`, LXDE — pcmanfm `[desktop]`.
10. **Рулинг, проверить владельцу:** явный флаг и выход из сеанса консервативнее
    блокировки целого канала Xfce, которая подавляет также личные настройки значков.
11. Xubuntu LightDM без локального конфига получает наш отдельный conf.d;
    при remove и пустом ключе он исчезает, вендорский файл не меняется.
12. wallpaper 3.1.0 — новая opt-in возможность; desktop 2.0.1 — исправление.

## Отвергнутые варианты

- Блокировать весь xfce4-desktop: затронет значки и прочие личные настройки.
- Править файл xubuntu-default-settings: это чужой пакетный слой.
- Править домашние каталоги от root или XML при работающем xfconfd: небезопасно,
  а кеш демона может потерять правку или восстановление.

## Приёмка

H-тесты: приоритет XDG, существующие личные свойства каждой DE, сохранность
неуправляемых свойств, исходное состояние после remove, повторная установка,
отказ на ссылках и активном сеансе. Отдельный H-тест автологина Xubuntu.
`STVOR_AGENT_DIR=.scratchpad/no-agent make ci`, один прогон одновременно.
PVE 192.168.202.206: только свободные 990001–990010 после qm list, четыре ВМ
параллельно, файлы /root/projects/wp156, ASCII в guest exec, один финальный снимок
на DE; затем stop/destroy --purge. До/после первого входа, remove, reinstall.
