# cloud-user

Библиотека: скрипт `get_cloud_user.sh` печатает имя пользователя cloud-init —
того, под кем расширения настраивают сеанс, автологин, ключи, автозапуск.
Хуков нет; ставится как зависимость.

## Что делает

cream раскладывает `get_cloud_user.sh` в `/opt/cream/ext/cloud-user/` и держит
его, пока от библиотеки зависит хотя бы одно расширение. Пути (`/home/<имя>`,
`user-data.txt`) берутся под `CREAM_ROOT`, `yq` ищется по `PATH` вызывающего и
запускается в чистом окружении. `user:` словарём даёт `.user.name`; имя
проверяется на допустимость.

stdout — только имя; диагностика — в stderr, имена в ней — без управляющих
символов (всё, кроме букв, цифр и `_.+-`, печатается как `?`).

| Ситуация | Код | Имя |
|---|---|---|
| есть `cloud-init` и `yq`, в userdata `user` (строка или словарь с `name`), иначе `users[0]` (так же) | 0 | из userdata |
| имя из userdata не проходит `^[a-z_][a-z0-9_-]{0,31}$` или это `default` (ссылка на `default_user` из `cloud.cfg`) | 0/1 | запасной путь (ниже), в stderr — `not a valid user name` |
| `cloud-init query userdata` не ответил, есть `/var/lib/cloud/instance/user-data.txt` | 0 | из файла |
| `cloud-init` есть, userdata ещё нет или `null` | 1 | — (гонка: вызывающий ждёт и повторяет) |
| userdata есть, а yq не дал имени (нет пользователя в seed, kislyuk/yq, сбой yq) | 0/1 | запасной путь (ниже), в stderr — `no user name from yq` |
| нет `cloud-init` или `yq` | 0 | первая учётка с uid 1000…65533, именем по тому же правилу `^[a-z_][a-z0-9_-]{0,31}$` и каталогом `/home/<имя>`; в stderr — `falling back to '<имя>'`; учётка с другим именем пропускается (`not a valid user name — skipped`) |
| нет и такой учётки | 1 | — |

## Установка

Ставится сама, по `depends` потребителя. Манифест потребителя:

```yaml
depends: [{name: cloud-user, version: ">=1.0.0 <2"}]
```

Хук потребителя:

```bash
user="$("${CREAM_ROOT:-}/opt/cream/ext/cloud-user/get_cloud_user.sh")" || exit 1
```

Удалить библиотеку, пока у неё есть зависимые, cream не даст.

## Известные ограничения

- `yq` — расширение [`yq`](../yq/README.md) (mikefarah/yq). Без него на образе
  с cloud-init библиотека уходит в запасной путь, который может выбрать
  вендорскую учётку раньше cloud-init-овской, поэтому `yq` ставится вместе с
  ней.
